# Linear Algebra Visual Lab

An interactive learning environment for undergraduate linear algebra students.

## Development

```bash
npm install
npm run dev
```

The application is a Vite React TypeScript frontend. Mathematical modules and visualizations will be added in later development chunks.

The current shell includes responsive sidebar navigation, dashboard, lesson, and playground layout primitives. No backend is required for the frontend-only MVP foundation.

## Validation

```bash
npm run build
```
